ResolveIQ

A Microsoft-sponsored capstone for internal operations support. Agents see a ticket queue, an infinite ticket canvas, and a knowledge wiki in one place. A chat assistant uses retrieval-augmented generation to draft replies with citations to wiki articles.

Final decisions stay with the human agent. Sensitive ticket data stays local, with no cloud deployment.

My role: product manager and UX researcher on a team of five. I translated support agents’ workflows into the retrieval interface, defined the product and technical architecture with the engineers (vector search over tickets and wiki content), and led usability testing with support agents and managers, tracking task completion time and accuracy to prioritize iterations. We presented the project to Microsoft stakeholders for use with future support tickets.

Built with a React front end, a Python backend, and a RAG pipeline on locally hosted language models. No cloud deployment, so no ticket data left the machine.

Job Application Research Agent

Give it a company name and a job posting. It extracts the requirements, searches the web for recent company news, and writes a one-page interview brief. A second pass checks the draft against the posting and the research, and the agent revises it.

My first test brief missed the role’s core topic because the research step only knew the company name. I traced it, fixed it with a role-specific search, and documented the before and after in the README.

Stack: Claude API with web search, Python, requests, BeautifulSoup.

Completed

Support Triage Agent with Feedback Loop

Classifies a support ticket, retrieves matching knowledge base articles, and drafts a cited reply for a human to approve, edit, or reject. Every decision is logged, and later runs reuse past human corrections as examples.

On 10 held-out tickets, drafts with feedback followed my style rules 5.9 of 7 times on average, versus 3.1 of 7 without. It is a small sample, and the README lists the caveats.

Stack: Python, Claude API, scikit-learn (TF-IDF retrieval), command-line review tool.
